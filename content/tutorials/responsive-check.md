# 响应式三档自检

课程作业要求网页在桌面、平板、手机上都正常。最省事的验收方法是固定看三个宽度，而不是凭感觉拖窗口。

## 三个宽度

| 宽度 | 代表设备 | 重点看 |
|---:|---|---|
| 390px | 手机 | 导航是否变抽屉、按钮是否好点、文字是否太小 |
| 768px | 平板 | 两列是否挤、卡片是否变形、图片是否溢出 |
| 1440px | 桌面 | 内容区是否过宽、留白是否失衡 |

## 一行代码检查横向溢出

在浏览器控制台执行：

```js
console.log(document.documentElement.scrollWidth, window.innerWidth);
```

两个数字应该相等；如果 `scrollWidth` 更大，说明页面有元素把宽度撑破了。

## 常见原因

1. 固定宽度：`width: 1200px` 在手机上一定溢出，改成 `max-width` + `width: 100%`。
2. 图片没限制：给 `img` 加 `max-width: 100%; height: auto;`。
3. 长链接/长英文：加 `overflow-wrap: anywhere`。
4. 绝对定位的装饰元素跑到屏幕外：给父级 `overflow: hidden`，或调整 `right/left`。
5. 导航项太多：手机端隐藏横向导航，改成汉堡按钮 + 抽屉。

## 检查顺序

1. 先看 390px，确认没有横向滚动、导航能用；
2. 再看 768px，确认两列布局不挤；
3. 最后看 1440px，确认内容没有散掉；
4. 在 Chrome / Edge / Firefox 各开一次，至少确认没有白屏和 JS 报错。
