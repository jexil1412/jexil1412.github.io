# 方向契约 · 天蓝 · 液态玻璃（v3.0）

> 取代 v2.1 的「索引卡 A」。落盘：2026-11-25。

```
Direction:  像清晨天空下的一层玻璃：天蓝渐变、白色半透明面板、细白高光边、柔和蓝色投影；内容像浮在空气里，但字必须清楚。
Audience:   同学、网友、之后可能的合作者；手机为主；先被质感留住，再读内容。
Reference:  苹果 Liquid Glass、毛玻璃窗、天空与云（不是 SaaS 落地页）。
Differs:    没有编号、没有卡片墙；首页只有字标；导航在左侧玻璃栏；作品用框内滑动切换。
Boldness:   全站唯一一处挥霍：按钮与作品卡的玻璃高光随指针移动；其余克制。
```

## 冻结的视觉值

**天空**

| token | 值 |
|---|---|
| `--sky-top` | `#A9D7FF` |
| `--sky-mid` | `#D6EEFF` |
| `--sky-bottom` | `#F3FAFF` |

页面底为三段渐变；两团固定径向光（白 0.72 / 浅蓝 0.45）在视口里，不跟鼠标、不做视差。禁止彩虹渐变与紫蓝渐变。

**玻璃**

| token | 值 | 用法 |
|---|---|---|
| `--glass` | `rgba(255,255,255,.42)` | 侧栏、slider 外框、卡片 |
| `--glass-strong` | `rgba(255,255,255,.62)` | 阅读面板 |
| `--glass-border` | `rgba(255,255,255,.72)` | 1px 高光边 |
| `--glass-shadow` | `0 24px 60px rgba(12,74,110,.16)` | 外投影 |
| `--glass-inset` | `inset 0 1px 0 rgba(255,255,255,.9)` | 顶部高光 |
| `--blur` | `24px`（移动 16px） | `backdrop-filter` |

- **两种玻璃**：模糊玻璃（侧栏、抽屉、顶部条、slider 外框、卡片）与轻玻璃（按钮、标签、箭头，无 blur）。
- 一屏模糊层 ≤8；不玻璃套玻璃；slide 内部不加玻璃。
- 文字对比度 ≥4.5:1；长文用高不透明度底。
- 降级：`@supports not (backdrop-filter)` → 实色 `rgba(255,255,255,.92)`。

**字体**

- UI：`"Segoe UI", -apple-system, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 字标 Jexil：优先用本地字体 `"Bodoni MT", "Bodoni 72", Didot, "Playfair Display", Georgia, serif`（italic）；首页大号 `clamp(96px, 16vw, 232px)`，侧栏 36px、移动顶部条 33px。转曲 SVG 也可，但必须包含全部字形，**J 顶部衬线 / l 升部 / i 点不得裁切**。
- 字号：40/48、28/36、20/28、16/28、14/22、12/18。

**颜色**：墨 `#0B2A3F`、muted `#3F6478`、唯一强调 `#0A84FF`、错误 `#B3261E`。

**圆角**：28（面板/框）、18（图/输入）、999（按钮/胶囊）。

## 结构规则

- 首页只放字标，没有介绍/身份/作品/按钮/编号。
- 左侧栏固定 264px，四组手风琴：关于（全部作品/App/网页）、今日（AI/音乐/动漫/游戏）、爱好、笔记（全部+标签）。
- 移动端：顶部玻璃条 + 全高抽屉；Esc 关闭。
- 作品并入关于，`FrameSlider` 一次一屏；箭头在框内；键盘 ←/→；边缘禁用；不循环、不自动播放。
- 全站没有 `00/01/02` 序号。

## 明确不做

- 紫蓝渐变、彩虹、彩色 glow、霓虹
- 玻璃套玻璃、每屏十几个 blur
- 卡片墙、三等宽特性卡充当主要内容
- 首页任何介绍或 CTA
- 联系方式、暗色模式、注册/评论/搜索
