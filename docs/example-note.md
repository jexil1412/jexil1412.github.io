# 这个站是怎么做出来的

这不是教程，只是一份施工记录。

## 三个决定

- 首页只放一个 **Jexil** 字标，不放介绍。
- 导航在左边，四个模块各自带子项。
- 作品放进「关于」，用框里的左右箭头切换。

> 玻璃不能铺满全站，只在侧栏、卡片和 slider 外框上用。
